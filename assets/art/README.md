# 百宝小道修 (Pocket Daoist) · 插画背景

本目录存放《百宝小道修》(Pocket Daoist) 的过场插画背景：章节过场 6 张、标题界面 1 张、结局 1 张。
全部由 `tools/gen_splash_art.py` 用 Python + Pillow 程序化绘制（剪影 + 渐变 + 雾气 + 粒子），
不依赖任何外部素材或在线出图服务，同一随机种子可复现完全相同的画面。

## 图片规格

- 尺寸 1216×832（横版），PNG，RGB 三通道。
- 画面层次：天空渐变 → 远景剪影（雾化、较浅）→ 中景主体剪影 → 近景细节 → 大气粒子 → 四角暗角。
- 月亮 / 血月位于画面上三分之一处，是视觉中心，带柔和光晕。
- 叠加了轻微颗粒噪点与色带，整体偏暗；画面中部刻意保持简洁，留出叠中文标题的空间。
- 平均亮度控制在 30~90 区间：过暗看不清，过亮压不住标题。

## 重新生成

脚本：`tools/gen_splash_art.py`

```bash
# 生成全部 8 张到 assets/art（默认种子）
python tools/gen_splash_art.py --out assets/art --seed 20241109

# 只重生成某一张
python tools/gen_splash_art.py --out assets/art --seed 20241109 --only chapter_3

# 输出到别处
python tools/gen_splash_art.py --out /tmp/art_check --seed 20241109
```

参数：

- `--out` 输出目录，默认 `assets/art`。
- `--seed` 随机种子，默认 `20241109`。同一种子生成的文件逐字节一致。
- `--only` 只生成指定文件名（不带扩展名）。

脚本运行结束会在终端打印每张图的尺寸、平均亮度、最大亮度与颜色数量，便于自检。

## 修改画面时的注意事项

- 剪影全部由多边形 / 曲线绘制，函数集中在脚本顶部的元素区（枯树、松、阔叶树、灯笼、牌坊、
  骷髅、长骨、祭坛台阶、铜柱、巨兽骨架等）。改形状优先改这些元素函数。
- 各章配色与构图差异由 8 个 `scene_*` 函数控制，互不共用。
- 遮罩一律用 255 填充，颜色在合成时施加（`composite(base, mask, color, haze=...)`）。
  直接往 L 模式遮罩里填颜色会报 `TypeError: color must be int or single-element tuple`。
- numpy 数组相关的随机数必须用 `npr = np.random.default_rng(seed)`，不要用 Python 的 `random` 对象。
