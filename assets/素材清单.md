# 《百宝小道修 (Pocket Daoist)》像素素材清单

全部素材由 `tools/gen_pixel_assets.py` 用 Python + Pillow 程序化生成，无抗锯齿、硬像素边缘，
深色描边，每张图 6~10 色，PNG（RGBA）。瓦片为不透明底，其余均为透明背景。

重新生成：

```bash
python tools/gen_pixel_assets.py            # 默认输出到项目根目录 assets/
python tools/gen_pixel_assets.py --out D:/x --seed 20261109
```

固定种子，重复运行结果完全一致（已用 SHA256 比对验证）。

## 接入约定（给主 agent）

- **尺寸约定**：图标 48×48（神通卡、遗物卡按 48×48 原尺寸显示，不要再缩放，保证像素锐利）；
  粒子 32×32（作为粒子贴图，实际播放尺寸可缩到 8~16 px）；道具按表中尺寸原样使用。
- **瓦片**：`terrain/*.png` 是 64×64 不透明贴图。要平铺必须开重复：在 `project.godot`
  加 `rendering/textures/canvas_textures/texture_repeat=1`，或在节点上设
  `texture_repeat = CanvasItem.TEXTURE_REPEAT_ENABLED`（用 `TextureRect` 拉大铺底时同样要设）。
  只平铺不改尺寸时，`Sprite2D` + `region_enabled` + `region_rect` 拉大区域也行，但边缘会拉伸，
  建议改成上面两种方式之一。
- **透明道具/图标**：PNG 带 alpha，直接用 `Sprite2D` / `TextureRect`；不需要额外抠图。
- **导入设置**：本批素材是像素画。Godot 4.7 已自动生成 `.import`（`mipmaps/generate=false`、
  `compress/mode=0` 无损），项目里 `textures/canvas_textures/default_texture_filter=1` 已是
  Nearest，整屏像素风不会被糊边。若之后单独调整导入参数，保持 Nearest + 关闭 mipmap 即可。
- **描边与配色**：统一描边色接近 `#0A0810`，发光色按类型分三系——青蓝（灵气/护体/符文）、
  血红（火/妖血/危险）、惨绿（鬼火/毒/诅咒），主色偏暗，与 64px 角色精灵同屏不违和。
- **配色上限**：每张图最多 10 色（瓦片 6~8 色），色阶已按出现频次压过，非必要不要再往图上加色。
- **`.import` 文件**：脚本只写 PNG，不碰 `.import`；Godot 4.7 打开工程时已自动生成本批素材的
  `.import`，无需再处理。
