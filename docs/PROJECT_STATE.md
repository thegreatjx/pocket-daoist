## 一句话现状

单关卡、单角色池（4 人可选）、可完整玩通一局的 V2 割草肉鸽原型：**只有第一关「青冥古林」**，道韵与超武合体已停用，剧情未接入。

## 一局的实际流程

1. `scenes/title.tscn` 首页选角色（4 人）→ 点「踏入秘境」。
2. `scenes/main.tscn` 局内：480 秒 / 10 波，波与波之间进入「天机阁」商店。
3. 升级三选一（`UpgradeUI`）：新法宝、原地淬炼、秘宝、属性强化。
4. 拾取青瓷罐、灵玉、宝箱，凑 4 槽法宝并淬炼到 Lv.8。
5. 第 10 波关底首领「苍鬃狼王」（`wolf`，26000 基础血量，血量过半进入狂暴二阶段）；另有 2 个小 Boss 在 2:30 / 5:15 出现（精英形态、体型放大、头顶血条、击杀掉天机宝箱），关底波次停刷杂兵与精英。
6. 结算后可进无尽模式（`main.gd::enter_endless_mode`），灵石/宗门/成就三条成长线留在 `Stats`。

## 已实现并生效

- **角色与动画**：4 位角色，1024 立绘 + 待机/跑步逐帧图集（`hero_motion_rig.gd` / `hero_frame_anim.gd`），首页展示与局内全套。
- **法宝系统**：4 槽环绕发射，Lv.1–Lv.8 原地淬炼，满阶形态质变，按境界/精英击杀开槽。
- **五行反应**：7 组，元素附着 + 单怪 ICD（普怪 2.4s / 首领 1.6s），反应 VFX 与音效有独立限流。
- **怪物阵容**：15 条原型（原 9 种 + 朱砂纸人/炽火丹灵/五毒蟾蜍/残剑剑傀 + 阴煞道童/镇魂石墩精英专属），9 种精英变体，关底首领按局顺序轮换（狼王 → 八卦丹炉 → 铜甲尸王 → 画皮狐妖 → 万剑魔尊）。资产流水线见 `docs/MONSTER_ART_PIPELINE.md`。
- **波次与刷怪**：10 波呼吸节奏 + 4 种队形（散射/盾兵小队/包抄/喘息），全部从**视口外**生成（`v2_spawn_director.sample_offscreen_point`）；每波配置 `elite_every_sec` 定时刷精英（前期 45 秒、4 分钟后 30 秒），精英从 3 条随机词缀中抽 1 条（御风加速 / 金刚加血免击退 / 爆煞死亡红圈爆炸），屏幕边缘有精英与首领指示箭头。
- **商店与升级**：天机阁（锁定/重随/折价出售）、升级三选一、宝箱淬炼。
- **打击感**：伤害飘字、闪白、顿帧（分级 + 140ms 最小间隔 + 每秒预算）、受击震屏。
- **音频**：24 路音效轮转池 + 事件冷却 + 密度动态低通；吸灵珠按五声音阶（宫商角徵羽）逐颗升调。
- **UI**：统一走 `scripts/ui/xianxia_ui_theme.gd`，HUD / 商店 / 法典 / 结算全套；首页有大头选人卡与高清立绘。

## 维护约定（与 AGENTS.md 一致）

- 数值、关卡、掉落、成就只改 `data/v2/*.json`，不在脚本里写第二套列表。

- 流程/界面/战斗阶段必须有显式状态字段，禁止用多个 bool 拼状态。
- 每次功能改动跑 `quick_check.py`，交付或出包跑 `--full`。
